# Protocolo prospectivo: CloverLeaf CUDA Fortran y daemon GPU

Fuente externa: `UK-MAC/CloverLeaf_CUDAFortran`, commit `6558a980d6094a70e815d445d0f561c11c0c8ef6`. Se usa un único proceso CUDA Fortran y una GPU A100. La fuente oficial requiere el parche de compatibilidad NVHPC 23.1 `cudaGetStreamDefault()` a `stream=0`; el job conserva el diff completo. La entrada fijada es `scripts/pacca/cloverleaf_screen_6000.in`: 3840×3840, `end_step=6000`, `end_time=250.0`, suficiente para que el límite de tiempo físico no corte los 6000 pasos. La calibración observó 8.16 s para 400 pasos y predeclara aproximadamente 122 s para 6000, dentro del objetivo 60--180 s.

Antes de cualquier EDP activo se ejecutan REF y tres pilotos sombra, bajo la política congelada y el modelo ONNX RF de tres señales con umbral 0.90. Cada piloto guarda `clover.out`, muestras NVML, log de decisiones, duración, energía de GPU NVML, energía RAPL de ambos paquetes y estado inicial/final de relojes. Se exige salida sin error y energía cinética final reproducible frente al REF con tolerancia numérica declarada antes de ejecutar: diferencia relativa <= 1e-8. La actividad GPU debe permanecer por encima de 5 % de utilización durante al menos 60 s de la fase continua.

La compuerta se evalúa sin abrir ni mirar EDP del brazo activo: pasar solo si la fase elegida dura >=60 s, al menos dos de tres pilotos sombra producen `memory_bound` con confianza >=0.90, y la actividad GPU es sostenida. Se registran los tres pilotos incluso si la compuerta falla. Si falla, no se ejecuta activo ni se infiere ganancia; un segundo candidato exige otro protocolo prospectivo.

Si pasa, el confirmatorio tiene cinco bloques balanceados y aleatorizados de REF, sombra y activo, misma entrada, umbral 0.90 y política congelada. Cada bloque conserva telemetría, decisiones y controles de reloj/energía de nodo. La variante de umbral reducido solo puede predefinirse después del análisis offline y solo para una aplicación nueva con 0.5 < P(memory) < 0.90; corre como experimento separado (.80 o .70 elegido antes de ver EDP), con .90 como control. No cambia el modelo congelado ni reinterpreta E-A/E-B.
